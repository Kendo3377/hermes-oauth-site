นโยบายความเป็นส่วนตัว

สำหรับแอปเชื่อม Google ชื่อ Hermes ที่ดูแลโดย Kendo3377 · ร่างวันที่ 1 ตุลาคม 2026

1. ขอบเขต

แอปนี้ใช้เป็นผู้ช่วยส่วนตัวบนระบบที่ผู้ดูแลควบคุม เว็บไซต์นี้มีไว้แจ้งข้อมูลแอปและไม่ได้เข้าถึงบัญชี Google ของผู้เยี่ยมชม

2. ข้อมูลและสิทธิ์ที่เข้าถึง

งานจัด Gmail ใช้สิทธิ์ OAuth เพื่ออ่านรายการป้าย ค้นหาข้อความที่ตรงกฎ รับรหัสข้อความ และเพิ่มป้ายให้ข้อความเหล่านั้น รายการสิทธิ์จริงอยู่ในหน้าจอยินยอมของ Google หากเปิดใช้เครื่องมืออื่น ขอบเขตข้อมูลที่เข้าถึงอาจรวมข้อมูลอีเมลหรือ Google Workspace ตามสิทธิ์และคำสั่งที่ผู้ใช้อนุญาต

ไฟล์สิทธิ์ประกอบด้วย access token และ refresh token เพื่อให้ระบบเข้าถึง API โดยไม่ต้องเก็บรหัสผ่านบัญชี Google

3. วัตถุประสงค์การใช้ข้อมูล

ข้อมูลที่เข้าถึงใช้เพื่อทำงานที่ผู้ใช้ร้องขอหรือกำหนดไว้ เช่น จัดหมวดหมู่ Gmail และรายงานผลการทำงาน งานจัดหมวดหมู่อัตโนมัติที่อธิบายบนหน้าแรกใช้กฎ ไม่ได้เรียกโมเดล AI เพื่อจัดหมวดหมู่

4. บริการภายนอก

ระบบติดต่อ Google เพื่อยืนยันสิทธิ์และใช้ Google APIs ระบบ Hermes ยังอาจใช้ผู้ให้บริการ AI และ Telegram ตามการตั้งค่า หากผู้ใช้สั่งให้เครื่องมือดึงข้อมูลบัญชีมาประกอบคำตอบ ข้อมูลอาจเข้าสู่บริบทสนทนาและถูกส่งไปยังบริการที่เกี่ยวข้อง จึงไม่ควรถือว่าข้อมูลทุกชนิดอยู่เฉพาะใน Raspberry Pi เสมอ

ก่อนเผยแพร่ ผู้ดูแลต้องยืนยันผู้รับข้อมูลและข้อจำกัดการใช้ข้อมูล Google ให้ตรงกับระบบจริง รวมถึงข้อกำหนด Google API Services User Data Policy และ Limited Use

5. การเก็บรักษาและความปลอดภัย

ไฟล์สิทธิ์อยู่ในระบบส่วนตัวที่จำกัดการเข้าถึง และอาจรวมในข้อมูลสำรองที่จำกัดสิทธิ์ ประวัติแชตและบันทึกงานอาจมีข้อมูลจากการใช้งาน ไม่เผยแพร่ไฟล์เหล่านี้พร้อมเว็บไซต์นี้

ระยะเวลาการเก็บประวัติ บันทึก และข้อมูลสำรองยังต้องให้ผู้ดูแลยืนยันก่อนเผยแพร่ฉบับจริง การถอนสิทธิ์ Google ไม่ได้ลบข้อมูลที่เก็บไว้ก่อนหน้านั้นโดยอัตโนมัติ

6. การถอนสิทธิ์และคำขอลบข้อมูล

ผู้ใช้ถอนการเชื่อมต่อได้ที่ หน้าการเชื่อมต่อกับบุคคลที่สามของบัญชี Google เลือกแอป Hermes และถอนสิทธิ์ ระบบจะไม่สามารถใช้งานสิทธิ์เดิมต่อได้ ส่วนข้อมูลที่อยู่ในระบบส่วนตัวและข้อมูลสำรองต้องจัดการแยกต่างหาก

ช่องทางติดต่อผู้ดูแลเพื่อขอลบข้อมูล: รอผู้ดูแลยืนยันช่องทางที่ยินยอมเผยแพร่

7. การเปลี่ยนแปลง

เมื่อการทำงานหรือการใช้ข้อมูลเปลี่ยนไป ผู้ดูแลจะปรับนโยบายให้ตรงกับการใช้งานจริงก่อนเพิ่มความสามารถที่เกี่ยวข้อง
